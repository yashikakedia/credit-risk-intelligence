# Credit Risk Intelligence Platform

End-to-end credit analytics project for loan default prediction, borrower risk segmentation, credit scorecard development, and portfolio loss estimation.

## Business Context
This project uses the LendingClub dataset as a simulated NBFC credit portfolio to identify high-risk borrowers and support better lending decisions.

## Dataset
Raw dataset: 2,260,701 rows and 151 columns.

Modeling dataset: 1,348,099 rows and 152 columns.

Target:
- 0 = Non-default / Fully Paid
- 1 = Default / Charged Off

Target distribution:
- Non-default: 80.02%
- Default: 19.98%

## Project Phases
1. Project setup and dataset understanding
2. Data cleaning and feature engineering
3. EDA
4. SQL analytics
5. ML default prediction
6. Credit scorecard and expected loss
7. Dashboard and live risk calculator
